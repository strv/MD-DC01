# MD-DC01

DCブラシモータをセンサレス速度制御することが可能なモータドライバMD-DC01のためのファームウェアリポジトリです。

センサレス速度制御は出力無効タイミングでの逆起電力計測により実現します。

## 仕様

- 電源入力
  - 6 ～ 24V
- 出力
  - 電圧：入力と一致
    - ※逆起電力が計測できるのは16V程度まで
  - 電流：MAX 3A
- PCとの通信方法
  - UART
    - オンボードUSB-シリアル変換(CH340)搭載
    - UART上でPC側と絶縁
    - 115200 1N8
      - MAX 150kbps
- 汎用コネクタ
  - J2 エンコーダ
    - 5Vトレラント
    - 基板上の未実装抵抗に部品を実装することで、供給電圧・プルアップ電圧の設定が可能
  - J4 シリアル通信
    - UART or I2C
    - 基板上の未実装抵抗に部品を実装することで、プルアップ可能
  - J5 DAC x2
    - デバッグ用
  - J6,7 ADC x2
    - 目標値入力等に利用
  - J8 GPIO x2
    - 汎用

# PCからの目標値指令

オンボードUSB-シリアル（115200 bps）から、改行で終わるコマンドを送ります。起動時はつまみ（ADC AUX0）で操作します。

| コマンド | 動作 |
| --- | --- |
| `T<mV>` | PC制御に切り替え、目標値を設定する（例: `T300`、`T-150`）。`±max_mv`に制限される |
| `K` | つまみ操作に戻す |

- PC制御中は、`T`を500 ms以内に送り続けてください。途切れると目標値は0になり、次の`T`か`K`までPC制御のままです
- つまみ、PCどちらの目標値も、制御では4 V/s（10 mV/制御周期）の傾きに制限されます
- 10 msごとに、次の順で報告します

`ms 状態 電源電圧[mV] 電流[mA] BEMF[mV] 目標[mV] 出力電圧[mV] 積分値`

# ビルド手順

1. STM32CubeMX で ioc ファイルを開く
1. GENERATE CODE でコード生成する
1. Inc,Srcのxprintfをビルド対象に追加する
1. 各自環境でコンパイル
